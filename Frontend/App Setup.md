#  App Setup

This guide walks you through setting up the **VH Mess Application** built with **React Native**, **Expo**, and **Expo Router**.

---

##  Prerequisites

Make sure the following tools are installed:

- [Node.js](https://nodejs.org/) (v18 or above recommended)
- [Expo CLI](https://docs.expo.dev/workflow/expo-cli/)
- [Git](https://git-scm.com/)
- A code editor like [VS Code](https://code.visualstudio.com/)

Install Expo CLI globally if not already:

```bash
npm install -g expo-cli
```

##  Clone the Repository

```bash
git https://github.com/pclubiitk/VH-Mess-Application.git

```
 Install Dependencies
Inside the project directory:
```bash
npm install
```

 Run the App
To start the development server:

```bash
npx expo start
```

This opens the Expo Dev Tools in your browser, where you can:

Open in an Android emulator

Launch in an iOS simulator

Scan QR code using Expo Go app on your phone
